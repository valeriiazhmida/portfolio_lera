# План сайту-портфоліо: чернетка

Nov 16, 2026 · @Валерія

## 1. Позиціонування

**Створюю вебпродукти, якими можна користуватись без інструкцій.**

Підзаголовок на першому екрані: UX/UI дизайнер для малого та середнього бізнесу.

Сама поведінка сайту має підтверджувати цю фразу: нічого не треба пояснювати, кожен екран має одну зрозумілу дію. Орієнтири за настроєм: лаконічність, мінімалізм, інтуїтивність і чіткі акценти, як у Revolut, monobank і Klarna.

## 2. Сторінки сайту

Сайт складається з семи сторінок: головної, трьох кейсів, «Про мене» і «Контакти», кожна українською та англійською.

| Сторінка | Призначення |
| --- | --- |
| Головна | За кілька секунд пояснити, хто автор, що тут проєктується і де дивитись роботи. |
| Кейс: лендінг для магазину годинників | Показати, як одна сторінка веде до однієї дії без зайвого шуму. |
| Кейс: LoopTrip, планувальник подорожей до культурних подій | Показати флоу організатора подій, який зрозумілий без пояснень. |
| Кейс: вебсервіс для медитацій | Показати роботу з багатосторінковим сервісом, де важливі спокій і ясність. |
| Про мене | Дати людини за портфоліо: досвід, підхід і те, що має довіру. |
| Контакти | Дати зрозумілий спосіб написати про проєктну роботу. |
